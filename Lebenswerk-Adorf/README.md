# Lebenswerk Adorf – Projektordner

Vorbereitung einer möglichen LEADER-Förderung (Region Diemelsee-Nordwaldeck) für eine offene
Bildungs-, Technik-, Kreativ- und Begegnungsstätte in einer bestehenden Gewerbefläche eines
denkmalgeschützten Gebäudes in Adorf (Gemeinde Diemelsee).

Angelegt: 2026-10-25 · Stand: **Entwurf / Bestandsaufnahme**

## Arbeitsregeln

1. **Nichts erfinden.** Keine Gebäudedaten, Maße, Preise, Förderbedingungen, Genehmigungen,
   Angebote oder Finanzierungsmittel ohne Beleg.
2. **Kennzeichnung** in allen Dokumenten:
   - `[BELEGT]` – durch Dokument/Quelle nachgewiesen (Quelle + Datum angeben)
   - `[ANGABE EIGENTÜMER]` – Aussage des Projektträgers, noch ohne Nachweis
   - `[ANNAHME]` – Arbeitsannahme, muss bestätigt oder verworfen werden
   - `[OFFEN]` – Information fehlt
3. **Quellen** immer mit URL bzw. Dokumentname und Abrufdatum.
4. **Trennung** von privater Wohnnutzung, gewerblicher Nutzung und gemeinnützigen Angeboten
   (siehe `10_Nutzungstrennung`).
5. **Maßnahmenbeginn:** Begonnene Arbeiten strikt getrennt von geplanten Fördermaßnahmen
   dokumentieren (siehe `11_Massnahmenstatus`). Vor Klärung mit dem Regionalmanagement
   keine neuen Aufträge für förderrelevante Maßnahmen vergeben.

## Ordnerstruktur

| Ordner | Inhalt |
|---|---|
| `00_Projektstatus/` | Projektstatus, nächste Schritte, Änderungsprotokoll |
| `01_Projektkonzept/` | Projektbeschreibung, Zielgruppen, Angebotsmodule |
| `02_Gebaeudedokumentation/` | Raumbuch (Räume, Maße, Zustand, Nutzung, Maßnahmen), Denkmal-Infos |
| `03_Grundrisse/` | Grundrisse, Schnitte, Lagepläne (Bestand + Planung) |
| `04_Fotos/` | Fotodokumentation (Außen, Innen, Schäden, Zustand vor Maßnahmen) |
| `05_Foerderunterlagen/` | LEADER-Anforderungen, Quellen, Formulare, Korrespondenz |
| `06_Kosten/` | Kostenstruktur, Angebote (`Angebote/`) |
| `07_Finanzierung/` | Finanzierungsplan, Eigenmittel, weitere Fördermittel |
| `08_Genehmigungen/` | Baurecht, Denkmalschutz, Brandschutz, Nutzungsänderung, Gewerbe |
| `09_Praesentation/` | Material für Beratungsgespräch / LAG-Vorstellung |
| `10_Nutzungstrennung/` | Abgrenzung privat / gewerblich / gemeinnützig |
| `11_Massnahmenstatus/` | Begonnene vs. noch nicht begonnene Maßnahmen |
| `12_Offene_Fragen_Nachweise/` | Fragen an die Förderberatung, Nachweisliste |

## Dateibenennung

`JJJJ-MM-TT_Thema_Version.ext`, z. B. `2026-10-25_Grundriss_EG_Bestand_v1.pdf`.
Fotos: `JJJJ-MM-TT_Raum-ID_Beschreibung_Nr.jpg`, z. B. `2026-10-25_R-EG-01_Fenster-Nordseite_01.jpg`.
