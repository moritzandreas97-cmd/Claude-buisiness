# Raumbuch – Erläuterung

Datei: `Raumbuch.csv` (Trennzeichen `;`, öffnet direkt in Excel/LibreOffice).
Stand: 2026-10-25 – **noch keine Raumdaten erfasst.**

## Felder

| Spalte | Erläuterung |
|---|---|
| Raum-ID | Schema `R-<Geschoss>-<Nr>`, z. B. `R-EG-01`, `R-OG1-03`, `R-KG-01` |
| Maße | nur gemessene Werte; Messdatum und Person in „Maße gemessen am / von“ |
| Zustand | gut / mittel / schlecht + kurze Beschreibung (Feuchte, Putz, Elektrik, Fenster …) |
| Denkmalrelevante Bauteile | z. B. Fachwerk, historische Türen, Treppen, Dielen – nur nach Auskunft Denkmalbehörde/Gutachten als „belegt“ |
| Nutzungsart | **privat** (Wohnen) / **gewerblich** / **gemeinnützig** / **gemischt** / **leer** |
| Geplante Nutzung | Modul M1–M6 aus der Projektbeschreibung |
| Notwendige Maßnahmen | Stichworte; Kosten werden in `06_Kosten` geführt |
| Maßnahme begonnen? | wichtig für Förderfähigkeit, Details in `11_Massnahmenstatus` |
| Status Daten | `[BELEGT]` / `[ANGABE EIGENTÜMER]` / `[ANNAHME]` / `[OFFEN]` |
